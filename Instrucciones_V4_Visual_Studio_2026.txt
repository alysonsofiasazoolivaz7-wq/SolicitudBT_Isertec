INSTRUCCIONES - SolicitudIT_Isertec V4
ASP.NET CORE 10 + SQL SERVER
PARA VISUAL STUDIO 2026

============================================================
1. QUE VAS A NECESITAR
============================================================

En Windows instala:

- Visual Studio 2026
- .NET 10 SDK
- SQL Server Developer o SQL Server Express
- SQL Server Management Studio (SSMS), recomendado

En Visual Studio 2026 debes tener instalada la carga de trabajo:

"ASP.NET y desarrollo web"

Para comprobar .NET:
1. Abre PowerShell.
2. Ejecuta:

dotnet --version

Debe aparecer una versión 10.x.

============================================================
2. DESCARGAR Y DESCOMPRIMIR EL PROYECTO
============================================================

Descarga:

SolicitudIT_Isertec_V4_Completa.zip

Descomprímelo, por ejemplo, en:

C:\Proyectos\SolicitudIT_Isertec_V4

NO abras solamente Program.cs.

El archivo principal que debes abrir es:

SolicitudIT_Isertec.csproj

============================================================
3. ABRIR EL PROYECTO EN VISUAL STUDIO 2026
============================================================

1. Abre Visual Studio 2026.
2. Selecciona:

   Abrir un proyecto o una solución

3. Busca:

   C:\Proyectos\SolicitudIT_Isertec_V4

4. Abre:

   SolicitudIT_Isertec.csproj

5. Espera a que Visual Studio termine de restaurar los paquetes NuGet.

============================================================
4. CONFIGURAR SQL SERVER
============================================================

Abre dentro del proyecto:

appsettings.json

Busca:

ConnectionStrings

Debes colocar la conexión de TU SQL Server.

Ejemplo si utilizas SQL Server Express:

Server=.\SQLEXPRESS;Database=soporte_bt_v4;Trusted_Connection=True;TrustServerCertificate=True;

Ejemplo si utilizas SQL Server local:

Server=localhost;Database=soporte_bt_v4;Trusted_Connection=True;TrustServerCertificate=True;

IMPORTANTE:
No copies literalmente estos datos si tu instancia de SQL Server tiene otro nombre.

============================================================
5. CREAR LA BASE DE DATOS
============================================================

Opción recomendada para una instalación nueva:

1. Abre SQL Server Management Studio.
2. Conéctate a tu servidor.
3. Crea una base de datos llamada:

   soporte_bt_v4

4. En Visual Studio abre:

   Herramientas
   > Administrador de paquetes NuGet
   > Consola del Administrador de paquetes

5. Ejecuta:

   Add-Migration InitialCreate

6. Después ejecuta:

   Update-Database

Entity Framework creará las tablas.

IMPORTANTE:
Si vas a utilizar una base de datos que ya contiene información del sistema PHP,
NO ejecutes Update-Database sobre ella todavía.
Primero debemos revisar y migrar los datos de MySQL a SQL Server.

============================================================
6. RESTAURAR PAQUETES
============================================================

Normalmente Visual Studio 2026 lo hará automáticamente.

Si necesitas hacerlo manualmente:

- Clic derecho sobre la solución.
- Selecciona:

  Restaurar paquetes NuGet

También puedes usar la terminal:

dotnet restore

============================================================
7. COMPILAR EL PROYECTO
============================================================

En Visual Studio 2026:

Compilar
> Recompilar solución

Si todo está correcto, no debe aparecer ningún error de compilación.

Si aparece un error:

NO cambies código al azar.

Copia el mensaje completo del error y guárdalo para corregirlo.

============================================================
8. EJECUTAR EL SISTEMA
============================================================

En la parte superior de Visual Studio selecciona:

HTTPS

Después pulsa:

▶ Iniciar

Visual Studio abrirá el navegador.

La dirección será parecida a:

https://localhost:xxxx

============================================================
9. CREAR EL PRIMER ADMINISTRADOR
============================================================

Después de ejecutar el proyecto, utiliza la pantalla de configuración inicial
incluida en la V4 para crear el primer usuario administrador.

Usa un correo/usuario de prueba inicialmente.

Después podremos crear los usuarios reales de la empresa.

============================================================
13. SI Add-Migration NO FUNCIONA
============================================================

En la Consola del Administrador de paquetes ejecuta:

Install-Package Microsoft.EntityFrameworkCore.Tools

Después:

Add-Migration InitialCreate

y:

Update-Database

============================================================
14. SI SQL SERVER NO CONECTA
============================================================

Comprueba:

- Que SQL Server esté iniciado.
- Que el nombre del servidor sea correcto.
- Que la base de datos exista.
- Que appsettings.json tenga la conexión correcta.
- Que Trusted_Connection corresponda al tipo de autenticación utilizado.

No cambies el proyecto completo por un error de conexión.

Primero revisa el mensaje exacto.

============================================================
15. MIGRACIÓN DEL SISTEMA PHP
============================================================

La V4 está pensada para reemplazar progresivamente el sistema PHP.

NO borres todavía:

- El proyecto PHP.
- La base de datos MySQL original.
- Los archivos de usuarios.
- Los archivos adjuntos.

La migración correcta será:

PHP/MySQL
      |
      v
SQL Server
      |
      v
ASP.NET Core 10
      |
      v
V4

Primero comprobamos que la V4 funcione con una base de datos de prueba.

Después migramos los datos reales.
